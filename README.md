# NOLLGAMES SNS + Website V2

구성:
- 반응형 NOLLGAMES 공식 웹사이트
- YouTube / Instagram 링크 연동
- 대표 YouTube 영상 Embed
- 신규 게임 데이터 추가 구조
- SNS 설정 도우미 `site-editor.html`
- YouTube/Instagram 이미지 템플릿
- SNS 운영 가이드

## 시작
1. 압축을 풉니다.
2. `site-editor.html`을 브라우저에서 열어 YouTube/Instagram/이메일/영상 ID를 입력합니다.
3. 생성된 `site-config.js`를 `js/site-config.js`에 덮어씁니다.
4. `js/games.js`에 실제 게임 정보를 입력합니다.
5. GitHub Pages 저장소에 전체 파일을 Push 합니다.

세부 운영 규칙은 `docs/SNS_OPERATION_GUIDE.md`를 확인하세요.
